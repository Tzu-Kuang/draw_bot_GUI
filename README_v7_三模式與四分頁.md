# 抽獎新盒監控 GUI v7 — 三種監控模式與四帳號分頁

## 1. Windows 安裝與升級

1. 先停止並關閉 v6 GUI 開啟的 Chrome，避免 Profile 被同時佔用。
2. 將 v7 ZIP **完整解壓縮**至一般資料夾（例如桌面）；不要直接在 ZIP 檢視器裡執行 `.bat`。
3. 第一次執行 `install.bat`，看到 `[SUCCESS]` 後再執行 `start_gui.bat`。
4. 已有 v6 帳號設定與 Chrome 獨立登入資料位於 `%LOCALAPPDATA%\KujiGuiBot`，v7 會讀取沿用；不要刪除資料夾。
5. 如安裝出錯，執行 `diagnose.bat` 並檢查 `install.log`。

## 2. 三種監控模式

GUI 的「監控模式」下拉選單：

| 模式 | 觸發條件 | 盒子順位 |
|---|---|---|
| **新 ID（指定順位）** | 指定第 N 盒出現本次監控從未見過的 `BOX-xxxxx` | 只監控第 N 盒（和 v6 相同） |
| **新 ID ＋ 恢復可點（指定順位）** | 指定盒出現新 ID；或者已看過的指定 BOX 從不可點→可點 | 只監控第 N 盒 |
| **任意順位新 ID** | 當頁任一位置出現本次從未見過的 BOX ID | 不理會第 N 盒；從頁面上方開始選第一個可點的新盒 |

三種模式均在**首次掃描建立基準，不點擊既有盒**。同一帳號此輪監控見過的 ID 都會記住；短暫從畫面消失又出現不算新盒。當新盒目前不可點時會留在待追蹤集合，直到出現可用按鈕，才嘗試點擊。

- 「恢復可點」專指從 `不可點/已售完` 轉為 `可點`；紫色排隊與橘色在原網站都屬「可點」，兩者變色不會視為恢復可點。
- 「任意順位新 ID」模式可同時追蹤多個新 ID；若有多盒可點，依目前網頁視覺順序依序處理。預設點擊一盒後停止刷新，避免跳過後續人工流程。
- 新 ID 的判斷以官方 BOX 編號為準，**不是剩餘抽數、按鈕顏色或總盒數**。
- 監控模式是共用設定；每個帳號的「第 N 盒」可分別在「編輯帳號」或帳號分頁盒子清單中設定。任意順位模式會忽略盒序。
- 切換模式／刷新秒數後，須**停止再重新開始監控**才會套用。重啟監控會重新建立基準，不點既有盒。

## 3. GUI 四帳號分頁與 Chrome 的差別

新增四個帳號後，**單一 GUI 主視窗上方**會出現四個帳號分頁。每個分頁顯示此帳號狀態、BOX 表格、獨立事件紀錄與「登入並監控、接續監控、停止、顯示 Chrome、最小化 Chrome」按鈕。最下方仍有固定的所有帳號合併事件紀錄。中間可捲動以修改網站網址、模式、帳號資訊。

**技術限制：四個帳號不會共用一個 Chrome 使用者設定檔，也不是同一個 Chrome 視窗內的普通分頁。** 同一 Chrome 設定檔的普通分頁共用 Cookie，若直接在四個網頁分頁登入 Bandai，會互相覆蓋登入狀態。此版本維持四個獨立 Chrome 環境，支持背景平行監控。

希望桌面只顯示 GUI：勾選「開始監控後自動最小化 Chrome」，完成登入後四個 Chrome 會最小化到背景；需要人工登入、驗證或檢查點擊結果時，在個別分頁按「顯示 Chrome」。也可以用「全部最小化 Chrome／全部顯示 Chrome」。**最小化不代表只有一個 Chrome 程序；仍消耗四份瀏覽器記憶體**，有些網站對背景或最小化視窗有限制；若偵測不穩，取消此功能並重啟。

## 4. 一番くじ ONLINE 正式站

保持前版：Bandai Namco ID 登入；完成驗證後回到同一商品的 ProductDetail，必要時自動點「購入する」，進入 SelectBox 頁面，先建立基準再監控新 BOX。

正式 SelectBox 頁依 `BOX-xxxxx` 可見文字和同一盒子的 `<a class="openModalButton">このくじ箱を見る</a>` 進行定位；紫、黃、橘的可用連結皆可辨識，灰色「販売終了」不點。點擊前會重新確認盒子 ID 與頁面順位。**只會點進看盒／排隊入口，絕不自動支付或完成訂單；不繞過 CAPTCHA、雙重驗證或排隊。**

## 5. 本機測試

1. 執行 `run_demo.bat`，開啟 `http://127.0.0.1:8765/`。
2. 新增 demo1、demo2、demo3、demo4 四個帳號，密碼都用 `demo123`。
3. 使用測試頁面的「新增盒子（插在第 1 盒）」驗證新 ID；使用「切換第 1 盒可點狀態」驗證恢復可點模式。
4. 確認 GUI 上方有四個帳號分頁，分別檢查 BOX ID、回報時間與事件紀錄。

## 6. 驗證與限制

- 本版 65 項離線單元測試通過；已在虛擬桌面進行四分頁切換、縮放與底部事件紀錄可視性測試。
- **尚未**以你的真實帳號在 Windows Chrome 和一番くじ ONLINE 實測；網站結構、頻繁刷新限制、登入失效或實際帳號互斥等仍可能影響運作。
- 請確認網站使用條款是否允許自動化和多帳號；若收到限制訊息，不要嘗試規避。
- 請勿分享帳密、瀏覽器登入 Cookie 或含敏感資料的完整日誌。
