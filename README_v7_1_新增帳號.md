# 新盒監控 GUI v7.1 — 找回「新增帳號」功能

## 本次修正

- **帳號分頁正上方的固定工具列**新增醒目的 `＋ 新增帳號 (Ctrl+N)`，不必捲動到網站設定區。
- 同一列新增 `編輯目前帳號`、`移除目前帳號`，並顯示目前帳號數量。
- 沒有任何帳號時顯示「尚未建立帳號」提示；新增後會**立刻建立該帳號分頁並切換選取**。
- `Ctrl+N` 可快速打開新增帳號視窗，原本中間設定區的新增帳號按鈕仍保留。
- 新增帳號時可填**顯示名稱、登入 Email／ID、登入密碼、專屬盒序**；相同顯示名稱不允許重複。密碼只有使用 Windows DPAPI 勾選記住時才儲存加密版本。
- 編輯帳號不會更改其獨立 Chrome Profile；移除帳號只從 GUI 設定清單移除，不會刪除 Chrome Profile 資料。

## 安裝／升級

1. 先關閉舊版 GUI 及其 Chrome 視窗。
2. **完整解壓縮** ZIP 檔案，不要在 ZIP 裡直接執行批次檔。
3. 先執行 `install.bat`，再雙擊 `start_gui.bat`。
4. 上方「帳號管理」列右側按 `＋ 新增帳號 (Ctrl+N)`，填寫資料並按「儲存」。
5. 畫面上方立即出現新帳號的分頁；可繼續新增第 2、3、4 個帳號。
6. 各帳號登入／監控仍使用各自的 Chrome Profile。原 v7 帳號及登入設定仍保留在 `%LOCALAPPDATA%\KujiGuiBot`。

## 三種監控模式（與 v7 相同）

1. 新 ID（指定順位）
2. 新 ID＋恢復可點（指定順位）
3. 任意順位新 ID

這三種模式共用網站設定，但不同帳號可設定自己的盒子順位。首次掃描只建立基準，不會點擊舊盒。

## 驗證

- 65 項原版邏輯測試成功。
- 3 項 v7.1 GUI 測試成功：固定新增按鈕、連續新增後立即出現分頁並保存、編輯和移除同步更新。
- 在 Linux 虛擬桌面驗證 GUI 顯示與操作；**尚未在你的 Windows／Bandai 帳號正式網站進行端到端驗證**。
- 依網站使用規範操作；自動化可能遇到登入保護、排隊或網站限制，不會跳過 CAPTCHA／驗證程序或代為付款。
