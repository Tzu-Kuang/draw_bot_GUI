# 多帳號快速操作（Bandai 購入後監控 v5）

- 每帳號有自己的 Chrome 設定檔與登入狀態，互不共用 cookies。保留 `%LOCALAPPDATA%\KujiGuiBot\profiles` 可以重用未過期的登入狀態。
- 新增帳號後按「全部登入並在完成後監控」：若一番くじ跳到登入入口，程式會嘗試按「バンダイナムコIDでログイン」。
- Bandai 官方登入頁若有同時可見的帳密欄位，且設定了帳密，會在 HTTPS 官方登入網域嘗試送出一次；驗證碼 / CAPTCHA / Passkey 仍須手動完成。
- 登入中不會刷新頁面；登入成功返回選盒頁且有匹配盒子時，各帳號才各自建立基準並開始監控。
- 驗證完但沒返回選盒頁：先選該帳號，再按「已手動登入：返回選盒頁並開始（選取帳號）」。
- **注意**：官方警告多帳號、多瀏覽器可能造成交易錯誤。遵循網站條款；不要嘗試繞過排隊、驗證或購買限制。

其他完整安裝步驟、CSS 設定、本機測試見 `README_使用說明.md`。

- v4 修正：填入帳密後才檢查「登入」是否可點；如灰色停用則保留 Chrome 給人工確認。
- 「登入密碼 CSS」請填 `input[type="password"]`，不要填真實密碼。

- v5：每個已登入帳號會獨立確認同商品 `ProductDetail.aspx`，單次點「購入する」入口，然後**等待選盒頁**；到達選盒頁且找到設定盒子 CSS 後才開始刷新。
